# hello-world-py

A tiny Python utility that prints a friendly greeting.

## Installation

```bash
git clone https://github.com/rasmus-maker/hello-world-py.git
cd hello-world-py
```

## Usage

```bash
python greet.py          # prints: Hello, world!
python greet.py Alice    # prints: Hello, Alice!
```

## Running tests

```bash
python -m pytest
```
